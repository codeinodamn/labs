# Полюс — прогнозирование рисков буровых станков

Аналитический продукт для выявления риска снижения производительности бурового оборудования.

В рамках проекта был реализован полный цикл работы с данными: от анализа и подготовки данных до построения ML-модели и визуализации результатов в Power BI.

### Что реализовано

* анализ данных по работе буровых станков;
* формирование индивидуального порога риска для каждого станка;
* сравнение моделей Logistic Regression, Random Forest и CatBoost;
* Feature Engineering и подбор гиперпараметров;
* рейтинг оборудования по вероятности снижения производительности;
* интерактивный Power BI-дашборд для мониторинга показателей и прогнозных рисков.

### Стек

`Python` · `Pandas` · `scikit-learn` · `CatBoost` · `Power BI`

**Формат проекта:** выпускная квалификационная работа по направлению «Бизнес-информатика».
