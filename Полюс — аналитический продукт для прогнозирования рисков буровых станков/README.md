# Полюс — прогнозирование рисков буровых станков

Аналитический продукт для выявления риска снижения производительности бурового оборудования.

## О проекте

Проект разработан в рамках выпускной квалификационной работы.

Реализован полный цикл работы с данными:
- анализ и подготовка данных;
- формирование целевой переменной риска;
- обучение и сравнение ML-моделей;
- Feature Engineering;
- подбор гиперпараметров;
- визуализация результатов в Power BI.

## Результат

Разработана ML-модель для оценки риска снижения производительности буровых станков и интерактивный дашборд для мониторинга оборудования.

## Стек

`Python` `Pandas` `scikit-learn` `CatBoost` `Power BI`
