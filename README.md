## Структура репозитория

* **Полюс — аналитический продукт для прогнозирования рисков** — дипломный проект: анализ данных, ML-модель прогнозирования рисков снижения производительности буровых станков и Power BI-дашборд.
* **data science** — проекты по анализу данных и машинному обучению.
* **power bi** — проекты и дашборды, разработанные в Power BI.
* **bd advocat** — проекты, связанные с базами данных.
* **web** — проекты по веб-разработке.
* **Курсовая работа** — учебный проект, включающий веб-приложение и базу данных.
* **certificates** — сертификаты о прохождении курсов и образовательных программ.
* **отзывы** — рекомендации и характеристики от руководителей.
